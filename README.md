# Customer Churn Analysis & Business Intelligence Dashboard

## Project Overview

Customer Churn Analysis is a data analytics project that analyzes customer behavior and identifies patterns related to customer churn.

The project uses customer information such as contract type, internet service, payment method, tenure, monthly charges, and customer characteristics to understand why customers leave a service.

An interactive Power BI dashboard was created to present the analysis and help identify customer segments with higher churn.

---

## Objectives

- Analyze customer churn patterns.
- Calculate the overall customer churn rate.
- Identify churn based on contract type.
- Analyze churn based on internet service.
- Analyze churn based on payment method.
- Study churn based on customer tenure.
- Compare churn between different customer groups.
- Identify major churn reasons.
- Present insights using an interactive Power BI dashboard.

---

## Dataset

The dataset contains information about 5,000 customers.

### Main Customer Attributes

- Customer ID
- Gender
- Senior Citizen
- Partner
- Dependents
- Tenure Months
- Contract
- Internet Service
- Phone Service
- Online Security
- Tech Support
- Payment Method
- Monthly Charges
- Total Charges
- Churn
- Churn Reason

The dataset was organized into customer, contract, internet service, and payment method information.
